# Divisy Brand Identity System

## Brand Positioning

**Divisy** is an international technology consultancy that operates from Power, not Force. We help B2B companies transform through authentic technological solutions that create sustainable, measurable impact.

### Core Brand Values
- **Authentic Alignment** - Deep understanding over predetermined frameworks
- **Sustainable Influence** - Attraction over coercion
- **Deep Partnership** - Collaboration over control
- **Clarity & Truth** - Honest assessment and transparent communication
- **Long-Term Impact** - Sustainable transformation over quick wins
- **Purpose-Driven** - Technology aligned with meaningful purpose

### Target Audience
- **Primary:** CTOs, Product Managers, CEOs at enterprise companies and scale-ups
- **Secondary:** Technology decision makers seeking transformation
- **Psychographics:** Value measurable results, authentic partnerships, long-term thinking
- **Geographic:** International (Spain, Colombia, Europe, Latin America)

### Brand Personality
- **Sophisticated** - Premium, refined, not flashy
- **Trustworthy** - Credible, reliable, enterprise-grade
- **Modern** - Contemporary but timeless
- **Clear** - Purposeful, direct, no ambiguity
- **International** - Global perspective, local understanding
- **Powerful** - Confident but not aggressive

## Typography System

### Font Family: Inter + IBM Plex Sans
**Rationale:** Professional, readable, international, modern

- **Primary:** Inter (sans-serif) - Modern, clean, highly legible
- **Fallback:** IBM Plex Sans - Professional alternative
- **System Fallback:** System UI stack for performance

### Type Scale

**Display (Hero, Major Headlines)**
- Display 1: `56px / 64px` - 600 weight - Hero headlines
- Display 2: `40px / 48px` - 600 weight - Section headlines

**Headings (Hierarchy)**
- Heading 1: `32px / 40px` - 600 weight - Page titles
- Heading 2: `24px / 32px` - 600 weight - Section titles
- Heading 3: `20px / 28px` - 600 weight - Subsection titles

**Body (Content)**
- Body Large: `16px / 24px` - 400 weight - Primary content
- Body Medium: `14px / 22px` - 400 weight - Secondary content
- Body Small: `12px / 18px` - 400 weight - Captions, labels

**Font Weights**
- Normal: 400 - Body text
- Medium: 500 - Emphasis
- Semibold: 600 - Headings, CTAs

---

## Form & Shape Language

### Border Radius System
**Philosophy:** Rounded but professional, not overly soft

- Small: `6px` - Buttons, badges, small elements
- Medium: `10px` - Cards, inputs, medium elements
- Large: `14px` - Panels, large cards
- Extra Large: `20px` - Hero sections, major containers

### Shape Principles
- **Moderate Rounding** - Professional, not playful
- **Consistent Application** - Same radius for similar elements
- **Hierarchical Sizing** - Larger elements = larger radius

---

## Spacing System

### Base Unit: 8px
All spacing multiples of 8px for consistency

- 0.5: `4px` - Tight spacing
- 1: `8px` - Base unit
- 1.5: `12px` - Compact spacing
- 2: `16px` - Standard spacing
- 3: `24px` - Comfortable spacing
- 4: `32px` - Section spacing
- 5: `40px` - Large section spacing
- 6: `48px` - Major section spacing
- 8: `64px` - Hero spacing
- 10: `80px` - Extra large spacing
- 12: `96px` - Maximum spacing

---

## Shadow System

**Philosophy:** Subtle depth, professional elevation

- Shadow 1: `0 1px 2px rgba(0, 0, 0, 0.06)` - Subtle elevation
- Shadow 2: `0 4px 12px rgba(0, 0, 0, 0.08)` - Card elevation
- Shadow 3: `0 12px 28px rgba(0, 0, 0, 0.12)` - Modal, overlay

---

## Motion & Animation

### Duration
- Micro: `120ms` - Quick interactions
- UI: `200ms` - Standard transitions
- Section: `320ms` - Page transitions

### Easing
- Standard: `cubic-bezier(0.2, 0.6, 0.2, 1)` - Smooth, natural

### Principles
- **Purposeful Motion** - Every animation serves a purpose
- **Respect Reduced Motion** - Honor user preferences
- **Smooth Transitions** - No jarring movements
- **Performance First** - Optimize for 60fps

---

## Layout System

### Container
- Max Width: `1280px` - Optimal reading width
- Gutter Mobile: `24px` - Side padding on mobile
- Gutter Desktop: `32px` - Side padding on desktop

### Grid System
- 12-column grid (implicit via Tailwind)
- Responsive breakpoints:
  - Mobile: < 640px
  - Tablet: 640px - 1024px
  - Desktop: 1024px - 1280px
  - Large: > 1280px

## Visual Style Guidelines

### Photography
- **Style:** Professional, authentic, diverse
- **Tone:** Bright, optimistic, but not overly staged
- **Subjects:** Real teams, real workspaces, technology in context
- **Avoid:** Stock photo clichés, overly corporate poses

### Illustrations
- **Style:** Minimal, geometric, professional
- **Use:** Icons, diagrams, conceptual representations
- **Avoid:** Cartoonish, overly playful styles

### Icons
- **Style:** Outline, consistent stroke weight
- **Size:** 16px, 20px, 24px standard sizes
- **Library:** Lucide Icons (consistent, professional)

### Data Visualization
- **Colors:** Use brand palette
- **Style:** Clean, minimal, data-first
- **Accessibility:** High contrast, colorblind-friendly

---

## Application Guidelines

### Do's
✅ Use brand colors consistently
✅ Maintain proper spacing hierarchy
✅ Apply typography scale appropriately
✅ Use subtle shadows for depth
✅ Respect reduced motion preferences
✅ Ensure WCAG AA contrast ratios

### Don'ts
❌ Mix color systems
❌ Use arbitrary spacing values
❌ Override typography scale
❌ Use heavy shadows
❌ Ignore accessibility
❌ Create jarring animations
